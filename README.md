## Sobre mim

Trabalho com desenvolvimento e portabilidade de ROMs customizadas baseadas em HyperOS/MIUI para dispositivos Redmi, principalmente portando para o **Redmi 12C** usando o **Redmi 13C** como doador. No dia a dia, isso envolve edição de smali, modificação de APKs, edição de partições de sistema e criação de módulos Magisk.

---

## O que eu faço

- **Portabilidade de ROMs** — porte de ROMs entre variantes de dispositivo (ex: Redmi 13C → Redmi 12C), incluindo ajuste de câmera, telefonia/SMS, cutout de tela e estabilidade geral do sistema
- **Edição de APKs e smali** — patches em `Settings.apk`, correção de crashes via null-checks, reempacotamento de `classes.dex`, edição de recursos ARSC e criação de UIs customizadas dentro de apps de sistema
- **Módulos Magisk** — criação de módulos para corrigir problemas em nível de kernel (reinícios, conflitos de SELinux, falhas de binder) e ajustes em tempo de execução via `system.prop` e `service.sh`
- **Debloat e otimização** — remoção de bloatware, serviços de telemetria e ajustes de performance via `build.prop`
- **Debug de sistema** — investigação de crash loops, falhas de assinatura de APK, e correção de schemas quebrados (ex: `TelephonyProvider`)

## Projeto em destaque

### ClancyOS (anteriormente EleceedOS)

Port customizado de HyperOS com branding e customizações de UI próprias, para o Redmi 12C.

- ROM portada a partir do Redmi Note 13 5G, com otimizações agressivas de performance
- Opção de kernel Amegakure e expansão de memória de até 4 GB
- v3.0.3.0 Global (Android 15) lançada
- v4 em desenvolvimento
- Distribuída via canal do Telegram
